# Joy

Joy 是由 **bddfs** 四人团队共同开发的游戏项目，目前名称为暂定代号。

## 当前阶段

首个原生单城 Demo 已完成一次实际试玩，目前整理第二轮验证方案。下一轮重点是已知后果预览、主动推理、回收资源取舍和网点成长；完整产品仍以三城远征为目标。

已确认方向为单人、Steam Windows/macOS、Godot .NET 与 C#。团队不设固定细分岗位；具体玩法边界、验证范围和待定参数以文档标注为准。
