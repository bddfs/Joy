# Joy

Joy 是由 **bddfs** 四人团队共同开发的游戏项目，目前名称为暂定代号。

## 当前阶段

项目处于玩法设计与开发准备阶段。团队采用设计先行的开发方式：先完善玩法设计与技术方案，明确首发范围，再进入实现与验收。

具体玩法、游戏引擎、编程语言、目标平台及成员分工，以后续确认的设计文档为准。

## 需求文档

- 当前评审：[Joy 需求规格说明书 v0.3](docs/requirements/Joy_需求规格说明书_v0.3.md) · [PDF 审阅版](output/pdf/Joy_需求规格说明书_v0.3.pdf)。本版已确认运输仅预览已知后果、疾走保留模仿参考，以及三城连续可完成的生成要求；其余待定项和数值按文档标注处理。
- 历史版本：[需求 v0.2](docs/requirements/Joy_需求规格说明书_v0.2.md)；[原始策划案 v0.1](docs/design/异常回收公司详细策划案_v0.1.md)。

## 团队协作

- 四名开发者使用 ChatGPT 辅助讨论与开发，通过 GitHub 协作。
- 已确认的设计与技术决策整理到仓库，作为共同的实现依据。
- 设计变更先记录并评估影响，再同步到实现。

## 美术与音频

- 美术主要由 AI 生成，或以团队手绘作品为基础进行 AI 润色。
- 音频初期以简单的背景音乐满足基本体验。

## 运行说明

游戏工程尚未建立。开发环境、安装步骤与运行方式将在技术方案确定后补充。
