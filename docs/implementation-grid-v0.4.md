日期：2026-10-27。基础分支 `codex/art-ui-v01`，基础提交 `44294c5`；本轮独立分支 `codex/grid-card-prototype`。用户确认五项新方向后要求制作可玩版本。本记录将实现、自动验证与实际界面操作分开记录。

## 实现范围

| 新方向 | 本版实际实现 |
| --- | --- |
| 角色技能树与个人牌组 | 林舟、许灯、陈墨三个角色；每人两条互斥短专精，每条两级；初始技能点与完成委托后的成长。每人六种专属牌，初始八张，允许6–10张、同名最多两张。界面支持逐张替换。 |
| 两层网格 | 7×5城市街区和9×7现场。城市通过道路寻路、阻断和修复影响可达性；现场有真实位置、距离、视线、障碍、门、箱柜、线索、服务铃与入口。 |
| 敌人与异常资产 | 旅馆回声侍者、医院镜柜、源头食痛者及伴生敌影；追声、畏光远程守望、近战追逐重击等行为。收容目标会成为回声铃、折叠衣柜、食痛者三件唯一资产。 |
| 三种场景的配置取舍 | 每次两名外勤，一名留守；个人职业牌带入现场，留守岗位在归队结算。每次最多带一件异常，留库与随队能力互斥；探索战斗使用同一地图、角色、手牌与资源。 |
| 全卡牌现场 | 11种常驻基础/交互牌、18种职业牌、3种异常能力牌。行进、搜查、拾取、攻击、护卫、收容、响铃、放下、撤离、待命、轮末均通过出牌执行。点击格子只选择目标，预览只读。 |

公司有资金、有限封装次数、网点、角色健康和七日期限。旅馆与医院完成后开放源头；处置源头且两个网点连通营业可胜利。成功撤离才支付合同、转移异常与出售所携物资。失败丢失本次现场货物，已用次数不退还，人员恢复最低可出勤状态，可以修整重试。已经完成的固定地点禁止再次刷奖励。

新增代码位于 `Core/GridPrototype/`、`Scripts/GridPrototype/`，默认场景为 `Scenes/GridPrototype.tscn`。旧M2规则、测试和场景仍保留。新版本采用独立 `grid-prototype-v1` 存档，带完整状态、随机序列、校验、原子替换与一份备份。

复用既有城市与地点插图，并新制作三张原生SVG异常图标，位于 `Assets/Grid/`。它们是本轮手工编写的矢量界面素材，不属于旧AI素材清单。角色和敌人目前以棋子与标记呈现，尚非最终人物美术。

## 画面与真实操作

主任务生成并目视检查城市、角色成长、收容物、现场与交战五种场景，另检查1280×720现场，共6张最终截图；附有控件几何记录。输出在工作区外层 `reviews/grid-prototype-v04/`，不随游戏导出。截图夹具包含构造的展示状态，仅用来检查界面。

使用 computer-use 对独立 `grid-prototype-ui-test` 存档执行真实鼠标操作：

1. 新局进入城市，选择林舟远行、陈墨交涉；对应技能点从1变0、专精等级变1。
2. 派遣旅馆，资金16→14，两名角色在A4/A5，每人2行动。
3. 选择行进牌与B3目标，预览阶段存档SHA-256保持 `2BF0DD0EEA3E47890567DAB06905AED03F1D57FAB01FFA731661468C1EDA798C`，未扣资源。
4. 实际打牌后林舟A4→B3，行动2→1，远行专精确实允许沿通路走两格；陈墨保持原位置与行动。
5. 打出搜查，记录现场证据；林舟行动1→0。
6. 打出结束回合进入第2轮，两人行动恢复2并分别抽3牌。
7. 保存返回标题后继续，位置、证据、资金、回合和手牌保持。存档文件SHA-256前后同为 `B0A03153F1802F3AE706D6D97A0B1020AAFA433DD76707BFDA8228DB16734029`，没有重复扣费或补牌。
8. 测试窗口运行日志无错误。完整三任务路线由核心公开API见证覆盖，不把局部鼠标检查写成真人完整通关。
