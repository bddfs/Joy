# Joy v0.3.0-m2.1 · M2 Windows 64 位预发行版

本次为开发者试玩的 M2 单城可玩原型，供团队体验推理、现场操作与经营资源取舍。

## 下载与启动

下载 Release 附件 **Joy-v0.3.0-m2.1-windows-x64.zip**，完整解压后运行 **Joy.exe**。请保留解压目录中的所有文件，不要只复制可执行文件。

包内附带自包含的 **.NET 8.0.31 运行时**，无需安装 Godot、.NET SDK 或另装 .NET 运行时。

构建所用的精确提交见包内 `build-info.json`；ZIP 校验值见 Release 附件 `SHA256SUMS.txt`，文件大小和最终包测试结果见 Release 正文。第三方许可证保留在包内 `Licenses` 目录。

## 本版可体验内容

- 七节点、五个经营日的城市经营；两队调度、委派、接管、驻站和统一日结。
- “镜中住客”推理样例：历史记录、有限容器、实际观察与候选判断共同推进调查。
- 每轮三行动、固定五卡槽；移动与查阅分离，行动和轮末常驻预览，模仿每次出勤耗尽。
- 唯一隔离工具及有限补充；侧房灯可出售、安装支援或暂存，源头使用专用收容箱。
- 自动检查点与继续游戏；失败后实物保留唯一遗落位置，可重新出勤取回。

## 存档

本版继续使用 **v2 存档**，目录为 Godot 的 `user://profile-m2`，主文件为 `save.json`，上一份完整备份为 `save.json.bak`。旧版 `user://profile` 保留，两个目录不混读。

继续游戏恢复最近一次成功保存的完整检查点。回合中尚未保存的操作需要重做；请以界面显示的实际保存位置和退出提示为准。

## 首次试玩与反馈

建议先体验不带传播压力的基础场景，自行阅读记录、提出假说，再通过行动验证。需要操作说明时可打开游戏内手册。

反馈时请附种子、经营日、现场房间及简短操作顺序，并说明：哪些观察改变了判断、预览是否容易理解、为什么选择撤离或继续、工具与灯具是否带来了实际取舍。遇到异常可附截图和相关日志；无需为了完成试玩反复猜答案。

## 验证与范围

源代码已通过 **784 项自动回归检查**。最终发布包的解压、启动及基本流程测试结果由 Release 正文记录；自动检查不代表首次玩家推理体验已经验收。

这是单城开发原型，尚未实现完整三城远征与连续生成，也不是正式发行版本。本次附件仅包含 **Windows 64 位**，不包含 macOS 构建。
