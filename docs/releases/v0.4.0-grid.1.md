# Joy v0.4.0-grid.1 · 网格卡牌玩法原型

本版验证“角色构筑、两层网格、全卡牌操作、异常收容与经营分配”的完整循环。它是独立玩法原型，沿用已有美术与 Godot 工程；数值、关卡规模和成长仍是试玩参数。

## 启动

完整解压 Windows 压缩包，运行 `Joy.exe`。保留旁边的 `Joy.pck` 和运行时文件夹，无需安装开发环境。

本版存档位于 `%APPDATA%\Godot\app_userdata\Joy · 异常回收公司\grid-prototype-v1`，每个成功操作后保存。旧 M2 存档保持独立。主档损坏时可读取上一份备份，不兼容未来版本时会提示而不覆盖。

## 一局的目标

在七个经营日的期限内完成暮灯旅馆、白榆医院与源头任务，并建立两个营业网点。先在城市选择两名外勤，其余角色留守；选择携带一件已收容异常，其余异常在公司发挥经营作用。城市道路、地点和施工都占据真实网格。

## 第一次出勤

1. 在“角色成长”查看三名角色的两条专精，使用初始技能点选择一条。每名角色有个人牌组，可以替换牌。
2. 在城市选择旅馆，确认两名外勤和路线后出发。
3. 现场先选角色，再选卡牌、点击目标格，阅读预览并打出。直接点击地图只选目标，不会移动。
4. 入口附近有可调查的线索。先读证据，再决定击退目标或满足条件收容。
5. 普通行进、交互、防身和撤离牌常驻；职业牌从个人牌库抽取。每轮每人两点行动、三张职业手牌。
6. 使用“结束回合”牌执行敌人意图并补充行动。观察敌人位置、攻击范围、灯区与回合期限。
7. 收容需要证据、足够低的目标生命、控制条件、收容工具和运输空间。击败目标可以处置任务，但不会获得该异常能力。
8. 两名角色都回到入口附近后，打出“整队撤离”。只有实际带回的成果才归库并兑现。

## 角色与收容物

- 林舟／测绘员：勘察、标定、投声与机动。留守提供经营收入。
- 许灯／灯光工程师：照明、闪光压制、隔离和维护。留守帮助道路恢复。
- 陈墨／收容官：束缚、防护、治疗与快速收容。留守帮助恢复人员和工具。
- 回声铃、折叠衣柜、食痛者可通过任务收容。每件只有一个实例，留库与随队能力互斥，现场使用消耗真实次数。

## 试玩重点

请尝试更换两名出勤角色、调整个人牌组、选择不同专精，再比较同一个地点的行动路线。取得第一件异常后，在下一次出勤比较“留在公司”与“带在身上”的差别。

本版为固定单城、三个手工现场，不包含三城生成、完整剧情、完整技能树或最终平衡。当前发布目标为 Windows；macOS 未验证。退出时请确认界面保存状态。
