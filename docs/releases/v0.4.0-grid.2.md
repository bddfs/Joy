# Joy v0.4.0-grid.2 · 天赋树试玩版

本版把三个角色的专精选项改为真正可点亮的天赋树。每名角色有职业根节点与三条成长分支，九个可购买节点；前置连线、已学节点、可学节点、锁定状态均直接显示。

## 如何体验

完整解压Windows压缩包后运行 `Joy.exe`。在公司界面打开“角色成长”，选择角色和节点，查看右侧效果与前置条件，点击“点亮节点”。新局每人有两点，每个节点花一点；完成新委托后继续获得技能点。允许在不同分支投资，深层节点仍要求学会对应前置。

节点分成三类：

- 数值：例如林舟的行进距离1→2格、精准投射伤害2→3；许灯的电弧伤害3→4；陈墨的收容范围增加。
- 机制：例如林舟的精准投射对已标定目标保留至少1生命；许灯的应急维护附带防护；陈墨的防护试探在空间足够时自动拾取箱内物资。
- 新牌：每名角色有三张可解锁特色牌，如探路疾行、联动标定、贯穿投射，随行灯、防护穹顶、连锁电弧，安抚协议、封锁阵、全队急救。

解锁特色牌后，到“个人牌组”将它加入或替换进牌组，再安排下一次出勤。解锁不会自动塞入当前手牌。牌组仍为6–10张、同名最多两张；锁定牌可以查看但不能配置。卡牌展示和执行预览会反映已学习天赋的实际效果。

## 存档

新版本保存于 `%APPDATA%\Godot\app_userdata\Joy · 异常回收公司\grid-prototype-v2`。没有新进度时，“继续”可以导入原 `grid-prototype-v1` 的网格存档：旧a/b专精层级转换成对应节点，旧技能点保持不变，现场位置、手牌、资源和任务进度继续保留。原v1文件不修改。

## 原型范围

城市与现场网格、两名外勤、一名留守、异常配置、三处任务继续沿用上一版。天赋树是本轮可玩范围，数值与组合还需真人试玩调整。完整三城、长篇剧情和macOS尚未验证。
