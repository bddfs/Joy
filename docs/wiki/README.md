## 条目状态怎么读

| 标记 | 含义 |
| --- | --- |
| **M2 可用** | 开发分支的 M2 内容工厂会投放，且具备正常玩法入口；不等于本次逐条手玩验证 |
| **条件出现** | 例如需拼接侧房、积累异动，或开启独立传播压力 |

| **历史 Legacy** | 上一版场景保留的内容，不是当前标题新局的随机池 |
| **完整版本规划** | 已写入设计方向，尚未成为 M2 的可玩内容 |
| **文档 / 实现差异** | 按两边各自证据说明；不把差异当作设计已经变更 |

## 常查问题

- **拿到合同物，为什么还不能接管？** 需要封装、成功归队、日终实际交付，并按地点要求确认归档规程。见[合同](contracts.md)。
- **盖好了，为什么不算营业点？** 新建次日起生效，还要有驻站、连通且未被入侵。见[营业资格](mechanics.md#operating)。
- **为什么模仿不能用？** 看参考牌、当前位置目标、真实库存与本次出勤是否已耗尽。见[卡牌](cards.md)。
- **灯具为什么不能出售？** 未封装、未归库、已安装、被预留或尚未到可用日都可能阻止处置。见[物品](items.md)。
- **疾走会打断模仿吗？** 不会；封装牌、驱离牌等其他非白名单行动牌仍会更新参考。见[卡牌](cards.md)。
- **为什么没有第二城？** 当前 M2 是单城验证；三城连续生成仍属[完整版本规划](sources.md#planned)。
