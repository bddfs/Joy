# v0.4.0-grid.2 天赋树实施记录

日期：2026-10-27。接续 `2361bd8` 网格原型。用户要求实际可点亮、有前置关系的树，节点分别提供卡牌数值提升、机制改变与特色新牌。

## 本版交付

- 三角色各有职业根节点、三条分支、每支三层，共27个可购买节点，按前置逐层解锁。
- 节点分为数值、机制、新牌三类；每节点1点，新局每人2点，完成新委托全员再得1点。允许跨分支投入。
- 9张特色牌仅在对应节点点亮后进入可配置牌库，玩家选择加入或替换。仍遵守6–10张牌组、同名最多两张；不自动修改牌组或现场手牌。
- 天赋树页面显示已学/可学/锁定节点、前置连线、费用和具体效果；点亮路径有颜色与短暂高亮反馈。牌库可查看锁定牌及其前置。
- 卡面、牌库、动作预览与实际结算共用天赋后的数值和机制。例如非致死投射、维护附带防护、试探箱柜后自动拾取等均实际执行。
- 新增代码为 `TalentCatalog`、`TalentTreeView`、`GridMain.Talents`；已有行动引擎、牌组与存档相应扩展。

## 存档兼容

游戏状态升级为Version2。旧v1的a/b等级映射为对应a1/a2或b1/b2节点，不额外赠点，保留旧能力与现场状态。非法节点、缺失前置、跨职业节点、重复节点、未解锁的新牌以及未来版本都拒绝读取或保存。

客户端使用 `grid-prototype-v2` 独立目录。只有尚无v2进度时，继续入口才从v1导入；导入成功后保存到v2，v1源文件不改动。已有v2损坏时使用本目录备份，不悄悄回退到旧版进度。GridSave亦支持直接迁移时的一次性 `.v1-backup` 保留。
